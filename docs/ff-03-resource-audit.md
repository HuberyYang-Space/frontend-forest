- 全部 27 项保留，现存项目 ID 不变；26 个独立旧图标地址均实际返回 image MIME，未因 asstes 拼写而猜测失效。

- Next.js 旧中文页主要描述 pages 路由，替代站限流，未验证到当前版本中文入口，先仅保留官方英文。
- SolidJS 改为官方当前文档及有可读中文内容、可追溯译者来源的 [社区翻译](https://solid.yayujs.com/)；原中英文重复入口消除。
- Svelte 更换为含符文与 Svelte 5 API 的社区中文文档；Angular.js 改为 Angular，amgular 标签改正，中文旧入口仅有空壳且维护状态未确认，先保留官方英文。
- Preact 改为官方 v11 文档；原中文地址实际为英文首页，删除虚假中文入口。Qwik 拼写改正，旧中文翻译未确认持续维护，先保留官方英文。
- Parcel 中文站已复现 404，保留官方英文。Rollup 中文更换为 cn.rollupjs.org；Babel 指向当前文档入口。
- 新版稳定号作为核验记录，不添加没有页面消费者的版本字段；uni-app 的 npm latest 为厂商日期编号，不把其中连字符自行判定为无稳定产品。

新增条目优先使用官网自带中文或官方仓库中文 README。VueUse 的 Nodejs.cn、Tailwind 的 Nodejs.cn、Bootstrap 的 BootCDN/Bootcss 译站及 Less 中文站按社区文档处理；MDN 使用官方站上的中文内容。Astro 中文局部横幅仍可能落后，VueUse 中文已标当前主版本；原有 Nuxt 中文标 4.5.0 而当前为 4.6.4，具体 API 以英文为准。原有 Solid、Svelte 等社区来源及移除的伪中文/过时入口见 [原有数据修正决定](#原有数据修正决定)。未核实真实中文正文与当前主版本时不填中文字段，不由 URL 中出现 `zh` 推断语言。

## 重要迁移与版本边界

- MicroApp采用当前jd-opensource仓库；旧micro-zoe仓库及旧GitHub Pages根地址返回404。
- CodeMirror迁至官方自托管仓库；LogicFlow旧域已售卖，采用site.logic-flow.cn；Recharts、Observable Plot、Paraglide使用新入口。
- Mako旧仓库跳转Utoo，旧Mako发布包与新Utoo Pack分开收录，不把不同引擎视为一次普通升级。
- Fresh使用JSR的@fresh/core，npm的fresh是无关包；Weex不使用不存在的weex-framework推断版本或采用量。
- Yarn使用现代@yarnpkg/cli-dist；Oxc表中为转译子包版本；FormCreate的Vue3使用next标签，该包下载统计包含各标签。
- Akita正确包为@datorama/akita，近月204,536；无scope同名包的354与本项目无关。明确说明归档，不将旧推荐的Elf视为当前仍活跃。
- 对维护停滞或结束维护的存量项目明示状态，包括Vuex、tsup、Recoil、Akita、Shoelace、AngularJS、Karma、Protractor、TSLint、Enzyme、Vuelidate、mxGraph和Angular Service Worker等。
- Leaflet 默认文档已进入 2.0 Beta，稳定包仍为 1.9.4；目录直达 [1.9.4 稳定版参考](https://leafletjs.com/reference-1.9.4.html)，避免文档与稳定版本错配。
- TDesign React、Vue Next 的真实 DOM 均显示中文“组件概览”，改为只标中文；Taro 旧入口客户端跳转后出现证书域名错误，未绕过安全提示，改用已核验中文 README 的官方仓库入口。
- Elm 安装包的数字包装后缀不作为预发布判据；只根据明确的 Alpha、Beta、RC 或官方实验声明标注阶段。
- Sass候选中文站主体仍为英文且版本落后、UnoCSS旧中文路径404、web.dev此CSS落地页中文参数未产出中文，均未提供虚假中文入口；Tailwind中文使用v4文档。

## 当前链路与版本限制

- [Jotai 文档](https://jotai.org/docs)在本机直接请求出现 TLS 错误，官方内容可由搜索工具交叉核验；不能据此认定站点失效。
- [Mako npm 页面](https://www.npmjs.com/package/@umijs/mako)的自动请求受 403 限制；包身份、版本与采用量通过 npm 注册表和官方迁移记录确认，页面访问仍需按实际网络环境复核。
- [CodeMirror 自托管仓库](https://code.haverbeke.berlin/codemirror/dev)返回 HTTP 200 挑战页；官方迁移公告确认归属，但不把挑战页当作已读到仓库正文。
- Flutter 已确认 2026-11-11 的 3.50 系列官方公告；存储清单接口未连通，未确认具体补丁号。

以上是可追踪的链路或版本限制，不代表全部外部入口均直接返回 200；收录结论与证据边界分开记录。
